# Recall

> 一款纯本地的经济与金融知识复习 App。双击图标即开，不依赖浏览器；**离线优先**，可联网更新内容。

## 它是什么

把经济学、金融学、世界热点三块知识拆成 **68 个独立概念**，每个概念一页、只讲一件事，
并且**每个概念的讲解方式都不一样**（曲线 / 公式 / 数据图 / 传导链路 / 时间线 / 计算器 / 误区对照…）。

刻意不用"定义 + 一段话"的电子书形态——那是浏览，不是复习。

| 分区 | 概念数 | 讲解重心 | 主导方式 |
|---|---|---|---|
| 经济学（宏观 / 微观 / 计量） | 24 | 机制与均衡直觉 | 曲线、传导图 |
| 金融学（股票 / 债券 / 基金 / 量化） | 24 | 可计算、可比 | 公式、计算器、数据图 |
| 世界热点（事件 / 数据） | 20 | 时间、因果、分歧 | 时间线、观点对比 |

## 怎么用

```bash
npm install
npm test        # 206 个用例
npm run package # 产出 release/mac-arm64/Recall.app
open release/mac-arm64/Recall.app
```

首次打开若被 Gatekeeper 拦住，右键 →「打开」（未做代码签名）。

## 几个设计决定

- **两级页面纵深**：分区首屏是「要点速览」（给结论），点「详情」才是完整解析（给原理）。速览页不渲染任何图表，保住「单页单概念」。
- **讲解方式多样性靠机制而不是自觉**：每个概念必须声明 3–5 种讲解方式，且**全库任意两条的组合不得重复**——由内容门禁脚本强制校验。
- **内容与用户数据分离**：`content.db` 随版本替换，`user.db`（进度、复习记录）永不覆盖。更新内容不会丢进度。
- **离线优先**：启动路径里没有任何一步等待网络。检查更新失败一律静默跳过，最坏结果是"还在用旧内容"，绝不会是"应用打不开"。

## 技术栈

Electron 44 + React 19 + TypeScript + Vite + `node:sqlite`（FTS5 全文检索）+ KaTeX + 自绘 SVG 图表。

## 关于内容更新

内容源是 `content/**/*.yaml`，发布产物是 `content-dist/` 下的两个裸文件（`manifest.json` + `concepts.jsonl`），
经 jsDelivr CDN 分发。发布是手动触发的：

```bash
npm run publish:content -- 2026.09.28
```

刻意不做 CI——内容必须人工复核事实与来源。
